Model a library book checkout system where books can be in states: available, checked_out, reserved, in_transit, or overdue.
The system tracks the status of each book, user borrowing limits (max 5 books), and reservation queues for popular books.
Define transitions for checkout, return, reservation, cancellation, and overdue processes, including how fines accumulate for overdue books.
Use variable names: book_state, user_checked_out_count, reservation_queue_length, days_overdue, fine_amount.
