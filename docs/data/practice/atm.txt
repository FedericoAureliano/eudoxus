Model an ATM transaction system with the following states: idle, card_inserted, pin_verification, transaction_selection, cash_withdrawal, balance_inquiry, and card_ejection.
The system should track the number of PIN attempt failures (max 3 before card retention), cash availability in the machine, and user account balance.
Define transitions between states based on user inputs, PIN verification results, cash availability checks, and transaction completion events.
Use variable names: state, pin_attempts, cash_available, account_balance, transaction_type, card_retained.
