Model an elevator system for a 3-floor building. The elevator can be called from any floor, and once inside, users can select their destination floor.
The elevator has states for moving up, moving down, and waiting at a floor with doors open or closed. The system should prioritize serving requests in the current direction of travel before changing direction.
Define transitions for door opening/closing, movement between floors, and handling floor requests both from inside the elevator and from call buttons on each floor.
Use variable names: current_floor, direction, door_state, requested_floors, called_from_floors.
